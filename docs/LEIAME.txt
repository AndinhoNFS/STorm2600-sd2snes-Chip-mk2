                   +$2400..+$3000, janela em +$3400, 20 tiles por linha, 2 buffers;
                   semente 7, +0,067 ns, main.bit md5 c8eb1755d36699ae172de8c2e2a58e75.
                   VERSAO ANTERIOR (v7):
                   NOVO NESTA VERSAO: jogadores de tamanho duplo e quadruplo (NUSIZ 5
                   e 7) comecam 1 pixel mais tarde, como no TIA real (ponte do River Raid).
                   DESDE A VERSAO ANTERIOR:
                     $2023 bit 4 = pausa (1 congela CPU, TIA, RIOT e audio, sem reset;
                                   bit 0 = run, bits 3:1 = mapper continuam iguais)
                     $2026 bits 5:0 = linhas descartadas no topo de cada quadro (0..63,
                                   vale a partir do quadro seguinte; volta a 0 no reset)
                     $202A = leitura do valor do skip
                     as 4 cores de cada linha sao amostradas no pixel 16 (antes: pixel 0)
                   FLAG DE HMOVE: na paleta por linha (4 bytes em +0x2300), o bit 7 do
                   byte COLUBK = 1 quando os 8 primeiros pixels da linha foram apagados.
                   POSICAO DOS OBJETOS corrigida no TIA: RESPx/RESMx/RESBL contam a
                   partir do clock em que o strobe vale (jogador +5, missil/bola +4);
                   antes os sprites saiam 3 pixels a esquerda do playfield.
                   ROM EM BLOCK RAM: depois de cada reset do SNES o core copia 16 KB
                   de 0x300000 (PSRAM) para um BRAM e so entao comeca a rodar.
                     R0 ($2020) bit 4 = ROM carregada (bit 6 = miss, bit 5 = FIFO de video)
                     R8 ($2028) = ciclos de CPU com miss (deve ficar 00)
                     R9 ($2029) = latencia maxima das leituras do carregador, em clocks
                                  de 96 MHz: e' a latencia real do slot da PSRAM
                     escrita no registrador 5 ($2025) zera miss/contador/latencia
                   Mappers 2K, 4K, F8 e F6. F4 (32 KB) NAO funciona: so 16 KB cabem.

Atencao
- O firmware.img SUBSTITUI o firmware do cartao (o atual tem 113049 bytes). Guarde
  uma copia do firmware.img atual antes de trocar.
- O md5 do firmware.img muda a cada compilacao, mesmo com o mesmo fonte; o valor
  acima vale so para este arquivo.
- Limitacoes conhecidas: ROMs com RAM Superchip nao sao recusadas (o core nao a
  implementa); o Mk.III nao foi compilado com o patch.
